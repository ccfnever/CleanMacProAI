# 扁平清洁扫刷图标方案

内置 imagegen 工具以 ../03-clean-brush.png 为参考生成。仅供选择，当前应用图标尚未更换。

- A-purple.png：紫蓝底、白色手柄、薄荷色刷毛。
- B-ivory.png：米白底、森林绿手柄、鼠尾草绿刷毛。
- C-mint.png：薄荷绿底、深青双色剪影。

提示词共同要求：将参考的斜向扫刷和左上四角星转为扁平图标，简洁几何曲线，纯色色块，简化为 3–4 块宽刷毛，居中的 macOS 圆角底座，外围透明，小尺寸易于辨认。去除立体体积、倒角、反光、光晕、投影和纹理，无文字和水印。

A: Solid periwinkle-indigo squircle, white handle with a circular hole, mint-aqua fan bristles, white sparkle; simple friendly geometric icon.
B: Warm ivory squircle, forest-green handle and sparkle, sage-mint fan bristles with dark-green separation; quiet minimal editorial style.
C: Pale mint squircle, dark-teal handle and three bristle lobes separated by mint negative space, dark-teal sparkle; bold duotone pictogram.
